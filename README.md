# Power BI-Global Sales Financial Performance Dataset (Week-1)


This repository contains my Power BI learning and practice projects. It includes different activities that helped me understand how Power BI works and how data can be prepared, connected, modeled, and analyzed to get useful information.

The projects cover **data loading, managing relationships, data modeling, and creating basic measures** in Power BI. I practiced working with different datasets and learned how to connect tables and organize data properly for analysis.

One of the projects focuses on a **Global Sales & Financial Performance Dataset**, where I worked with sales and financial data to understand the information and create meaningful insights using Power BI.

Overall, these projects helped me improve my practical knowledge of Power BI and develop my basic data analysis and visualization skills.
